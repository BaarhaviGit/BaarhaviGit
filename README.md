## What I'm building

I'm a full-stack developer who loves turning ideas into real, working things — from the login page all the way down to the database. My projects mix the frontend and the backend into complete apps, and I keep pushing toward **scalable systems** and **AI-assisted developer tools**.

My current focus includes:

- Full-stack web apps with **React, Node.js, Express, MongoDB and MySQL**.
- Cloud and DevOps: **AWS, Firebase, Docker and Kubernetes**.
- AI-powered developer tools — from error fixing to automation and coding assistants.
- Real-time backends (WebSockets, Socket.io) and lightweight frontend-only experiments.
- Learning in public and contributing to open source, one merged pull request at a time.
